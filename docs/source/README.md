# The source documents

What the project started from, kept as they were and not edited since (moved here on 2026-11-06):

- [`the_escapists_3d_complete_game_design_document.md`](the_escapists_3d_complete_game_design_document.md): the
  game design document (the GDD), the source of truth for the game.
- [`game_idea.md`](game_idea.md): the first feature list.
- [`tech_plan.md`](tech_plan.md): engineering details, used only where the GDD says nothing. Its opening line,
  addressed to the tool of the time ("copy this into PLAN.md…"), no longer applies: the plan is
  [`../PLAN.md`](../PLAN.md).

And one written since, the second mode's design (2026-11-13), which grows with its stages:

- [`city_escape_design.md`](city_escape_design.md): City Escape, a generated post-apocalyptic city to survive and
  escape: the premise, the city, the loop, the rules, the story and the ways out, and what it shares with the
  prison game. Its roadmap is [`../phases/10-city-escape.md`](../phases/10-city-escape.md).

Where the project departed from them, and why, is in [`../decisions/`](../decisions/).
